# 海岬试验室 · 点版核销账（Book）

按各站实收版核销勘误。中心与各站分用 SQLite 库，全部放在同一个 Book 目录下，
仅依赖 Python 3 标准库。

## 目录结构

```
book.py                 Book 主类、Package（件）、Receipt（首执）、异常
demo.py                 题面 X/Y 三版、甲/乙两站完整演示
verify.py               单一测试入口（运行 tests/ 下全部 unittest）
tests/test_book.py      34 项回归
.pointwise-runtime.json 运行清单（version=1, kind=cli）
```

运行期 Book 目录内容：

| 文件 | 归属 | 内容 |
| --- | --- | --- |
| `center.db` | 中心 | 批次现行行（`rows`）、冻结版本快照（`versions`） |
| `station_<站>.db` | 各站 | 班账 `ledger`、已收版 `received`、派件回执 `dispatches`、班账 `ledger_books` 及逐点台账 `ledger_book_rows` |
| `.center.key` | 中心签发密钥 | HMAC-SHA256 验据密钥，中心持有、站方同目录核验 |

站方验收只读本站库、件与验据，不打开中心库（有测试移走 `center.db` 验证）。

## 数据约定

- 行：`(点, 整数或 None, (原批号, 行号))`；批内点唯一、出处唯一。
- 撤下：点位保留、值记 `None`，缺测在合计/差额中按 0 计。
- 件 `Package`：`station / batch / num / prev / target / rows`，`first` 即 `prev == 0`。
- 号固定绑定 `(站, 批, 目标版)`：`Book.dispatch_num(station, batch, target)`
  为纯函数（SHA-256 派生），站方可独立核算，错号/错绑一律拒收。
- 验据：对件的规范 JSON（键排序、紧凑分隔）做 HMAC-SHA256，
  件内任何字段被改（含少行、错绑）都会签名不符。

## 接口

| 方法 | 规则 |
| --- | --- |
| `import_batch(批, 行列)` | 建批；校验行形、批内点/出处唯一；重复建批拒收 |
| `correct(批, 旧出处, 新值, 新出处)` | 验同批现行出处命中后改值/换出处；新出处不得占用他点；`新值=None` 为撤下 |
| `freeze(批)` | 返 `FreezeResult(ver, rows, missing, total)`：版号批内递增、原序行、缺测数、合计；版本快照不可变，旧版不变 |
| `dispatch(站, 号, 批, 目标版)` | 号不符拒收；同参已成功验收→回原首执；否则回 `(件, 验据)`。初报（前版 0）装全行；补报只发本站实收前版至目标的变更行，同值换出处、零转缺测照发 |
| `accept(站, 件, 验据)` | 验据→站/号/批绑定→前版相符且目标前进→逐点错绑/少行核验；全部通过后新版、班账、首执**同次事务提交**，成功返 `Receipt`，任一检查失败回滚、无新增。原件重复投递幂等返原执 |
| `read(站, 首执)` | 重开原班账：前后版、原序行（验收时整账冻结快照）、缺测数、合计、逐点旧新行与差额、净差 |

差额口径：`差额 = coalesce(新值,0) - coalesce(旧值,0)`，净差为本次各点差额之和。

## 题面示例（demo 实跑数值）

批 B1，点 X、Y：V1 `7, 0` → V2 `10, 缺测` → V3 仅换 X 出处。

- 甲站 V1 起逐版核销：V1→V2 核销两点，净增 **+3**（X +3、Y 零转缺测 0）；
  V2→V3 只收 X 一行、净差 0。
- 乙站从 V2 起：V2 是初报装全行；V2→V3 补报只核销 X、净差 **0**。
- 两站最终班账均为 **合计 10、缺测 1**。

demo 另含拒收矩阵（篡改值、错绑到站、少行、前版不符、错号）、
同参领原执、坏验据拒收无新增后换前版重发成功。

## 运行

```bash
python3 -B verify.py     # 34 项测试，失败非零退出
python3 -B demo.py       # 两站账演示（自建临时目录，结束即清理）
```
